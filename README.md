# lucgoudreault.com

Site de Luc Goudreault, administrateur de sociétés et conseiller stratégique de dirigeants.

Site statique (HTML, CSS, JS), publié par GitHub Pages depuis `main`. Les règles de travail, le système de design et la procédure de mise en ligne sont dans [CLAUDE.md](CLAUDE.md). L'ancien site Framer est archivé dans [archive/](archive/README.md).

Aperçu local : `python3 scripts/serve.py`, puis http://localhost:8000/
